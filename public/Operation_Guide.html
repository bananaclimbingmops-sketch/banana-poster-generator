1. 简介

香蕉攀岩运营工具是一款专为攀岩馆设计的自动化视觉内容生成平台，旨在简化和加速日常运营中所需的海报和贴纸的制作流程。工具目前包含两大核心功能：

  • 换线海报生成器：快速生成用于通知换线信息的专业海报，支持单次和多次换线两种模式。
  • 定线员贴纸生成器：为定线员制作个性化的圆形贴纸，可用于海报、社交媒体或活动现场。

2. 换线海报生成器

此功能用于创建包含详细换线信息和定线员介绍的宣传海报。所有修改会实时反映在右侧的预览区中，所见即所得。

2.1. 海报信息

在左侧的「海报信息」面板中，您可以填写海报的核心内容。

字段说明
① 标题海报的主标题，例如"香蕉攀石 · 华发中城商都店"。
② 副标题对标题的补充说明，例如"2月换线信息"。
③ 换线模式单次换线：适用于只有一次换线安排的情况。
多次换线：适用于一周内有多个不同日期、不同区域的换线安排。
④ 换线时间表填写换线的具体时间和区域说明，支持多行文字。
⑤ 闭馆换线开启后，海报上会明确标注"闭馆换线"。
⑥ 换线区域填写本次换线的具体岩区，例如"全场"、"A/B/C 区"等。

单次换线模式

适用于只有一次换线安排的场景。直接填写换线时间表、是否闭馆、换线区域即可。

多次换线模式

此模式专为复杂的周度换线计划设计，可在一个海报上清晰展示每天的换线安排。

切换为多次换线模式后，您可以动态添加多条换线安排，每条安排可包含日期、时间和区域描述，并支持拖拽排序。

2.2. 添加定线员

海报的核心元素之一是定线员的介绍。本工具提供单个添加和批量导入两种方式。

单个添加

  1. 上传照片：点击或拖拽定线员照片到上传区域（支持 JPG、PNG、WebP）。为获得最佳效果，建议使用人物清晰、占比较大的照片。
  2. AI 自动抠图（可选）：开启右上角的「AI 自动抠图」开关，系统会自动去除照片背景，处理时间约 10–20 秒。
  3. 填写名字：输入定线员的姓名，将显示在海报卡片上。
  4. 填写简介：输入定线员的头衔或成就，例如"国家一级定线员"、"IFSC 认证定线员"。
  5. 选择身份：选择"定线员"或"特邀定线员"，两者在海报上的样式有所区别。
  6. 选择国籍：从下拉菜单中选择国籍，海报上会自动显示对应国旗图标。
  7. 点击「添加定线员」：该定线员卡片将出现在下方列表中，同时预览区实时更新。
提示：如果人物在画面中占比过小，系统会在上传区域下方显示橙色提示，建议裁剪原图后重新上传，以确保海报上人物清晰可辨。

批量导入

如果您需要一次性添加多位定线员，可以点击「批量导入」按钮，支持从本地文件夹或 ZIP 压缩包导入。

批量导入要求将所有定线员照片和一个 info.json 文件放在同一文件夹中，文件夹结构如下：

climbers/              ← 文件夹名称任意
├── info.json
├── 张三.jpg
├── 李四.png
└── 王五.webp

info.json 的格式如下，每位定线员对应一个对象：

[
  {
    "name": "张三",
    "bio": "国家一级定线员\n全国冠军",
    "role": "regular",
    "nationality": "中国",
    "photo": "张三.jpg"
  },
  {
    "name": "John Doe",
    "bio": "IFSC Certified Setter",
    "role": "special",
    "nationality": "美国",
    "photo": "john.png"
  }
]
字段类型说明
name必填定线员姓名
bio必填简介，支持 \n 换行
role可选regular（定线员）或 special（特邀定线员），默认 regular
nationality可选国籍名称，例如"中国"、"美国"
photo必填照片文件名，需与文件夹中的文件名完全一致

管理已添加的定线员

  • 拖拽排序：在已添加的定线员列表中，按住并拖动卡片可调整在海报上的显示顺序。
  • 编辑：点击卡片上的编辑图标，可修改该定线员的所有信息。
  • 删除：点击卡片上的删除图标，可移除该定线员。
  • 一键清空：快速清除所有已添加的定线员，方便重新开始。

2.3. 导出设置

完成所有信息填写后，在左侧底部的「导出设置」区域设置最终输出格式，然后点击「下载海报」按钮生成文件。

选项说明
60×90 cm标准大海报尺寸，适合场馆展示墙、入口处张贴。
60×80 cm中等尺寸，适合展架或较小的展示区域。
59×79 cm适配特定展架规格的尺寸。
PNG 格式高质量图片，适用于线上分享（微信、微博等）和部分印刷场景。
PDF 格式矢量格式，推荐用于专业印刷，可确保最佳打印质量。

2.4. 历史记录

系统会自动保存您最近 20 次生成的海报配置。点击页面右上角的「生成记录」按钮，可以查看历史记录，并一键恢复之前的配置，方便复用或微调。

3. 定线员贴纸生成器

此功能用于快速生成风格统一的圆形定线员贴纸。系统内置多级人脸检测算法（YuNet DNN → Haar Cascade 正面 → Haar Cascade 侧面），可自动识别人脸并进行智能构图。

3.1. 操作流程

  1. 上传照片：点击或拖拽定线员照片到上传区域（支持 JPG、PNG、WebP）。建议使用人物清晰、正面或侧面的照片，人物在画面中占比越大，构图效果越好。
  2. 填写定线员姓名：输入姓名，将显示在贴纸底部的标签区域。
  3. 选择国籍：点击对应的国旗图标选择国籍，贴纸上会显示对应国旗。如选择"无"，则不显示国旗。
  4. AI 自动抠图（推荐开启）：开启后，系统会自动去除照片背景，使人物与黄色贴纸背景完美融合。处理时间约 10–20 秒。
  5. 点击「生成贴纸」：系统自动进行人脸检测和智能构图，并在右侧预览区生成 945×945px 的高清贴纸。
  6. 下载：点击右上角「下载 PNG」按钮，保存最终贴纸文件。
提示：贴纸输出为 945×945 像素的高清 PNG，满足 8cm×8cm @300dpi 的印刷要求，可直接送印。

3.2. 手动调整构图

如果自动构图的效果不理想（例如人物位置偏离、大小不合适），您可以点击预览图下方的「手动调整构图」按钮，进入拖拽微调模式。

操作功能
拖动预览区在圆形预览区域内按住并拖动鼠标（或手指），可以自由移动人物的位置。
缩放滑块使用底部的滑块可以放大或缩小人物，调整范围为 30% 至 250%。
确认构图调整满意后，点击「确认构图」按钮，系统会根据您的调整重新合成最终贴纸。
重置点击「重置到自动构图」链接，可一键恢复到系统最初的智能构图状态。
取消点击「取消」按钮，退出调整模式，回到预览状态。
注意：手动调整后，预览图下方会显示"✓ 已手动调整"标记，下载时将下载您调整后的版本。国旗和姓名标签始终显示在人物图层上方，不会被遮挡。

4. 常见问题

为什么海报预览区的图片看起来有些模糊？
为了提高网页性能和响应速度，预览区使用的是低分辨率的压缩图。最终下载的 PNG 或 PDF 文件是全高清的，请放心使用。
AI 抠图失败或效果不佳怎么办？
AI 抠图对背景复杂、光线不佳或人物与背景颜色相近的照片效果可能会下降。建议使用背景简洁、光线明亮的原始照片。如果抠图效果不理想，可以关闭该功能，使用原始图片直接生成。
如何让贴纸的自动构图效果最好？
上传人物面部清晰、无遮挡、占画面比例较大的照片。避免使用远景全身照或面部被严重遮挡的照片。如果自动构图不理想，可以使用「手动调整构图」功能进行微调。
批量导入时 info.json 中的 nationality 字段应该填什么？
填写中文国籍名称，例如"中国"、"美国"、"日本"、"韩国"、"英国"、"法国"、"荷兰"、"意大利"、"俄罗斯"、"新加坡"、"马来西亚"、"加泰罗尼亚"。如果不需要显示国旗，可以填写"无"或省略该字段。
历史记录最多保存多少条？
系统自动保存最近 20 条海报生成记录。超过 20 条后，最旧的记录会被自动清除。历史记录保存在浏览器本地，清除浏览器数据后记录会丢失。
